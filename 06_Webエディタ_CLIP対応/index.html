入力

数字・文字選んだセルにそのまま入力を始める
Enter / F2 / ダブルクリック入力欄を開く（日本語入力はここから）
Enter（入力中）確定して「打ち」の数だけ下へ進む
Shift+Enter / Esc確定して1コマ上へ ／ 入力をやめる
0×（空セル）
-継続
[話者]本文セリフ列で話者と本文に分けて入る
範囲を選んでセリフを入力選んだ範囲がそのセリフの長さになる
Alt+Lセリフの始まりから選んだ範囲の下まで、セリフの長さを合わせる（伸ばす・縮める）
Alt+1〜4 / Alt+0打ち数を 1〜4コマ ／ 自動 にする

選択・編集

矢印移動（Alt+↑↓ で6コマずつ）
Shift+矢印 / ドラッグ範囲選択
Ctrl+A全部選択
Ctrl+C / X / Vコピー ／ 切り取り ／ 貼り付け
Delete選んだセル（範囲）の入力を消す
Insert / Shift+Insert選んだ列 ／ 全列に、選択の高さ分コマを挿入
Ctrl+Delete / Ctrl+Shift+Delete選んだ列 ／ 全列のコマを削除して詰める
Ctrl+Z / Ctrl+Y元に戻す ／ やり直し

移動・ファイル

PageUp / PageDown前 ／ 次のシート（Ctrl+↑↓ でも可）
Ctrl+Home / Ctrl+End最初 ／ 最後のシート
Ctrl+O / Ctrl+S開く ／ 保存

保存していない作業があります
